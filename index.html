uNotes

uNotes é um aplicativo de anotações pessoais para Windows e Android, baseado no Joplin, um projeto de código aberto, que sincroniza as suas próprias notas com o seu próprio Google Drive.

  • As notas são criptografadas no dispositivo antes de sair dele: criptografia de ponta a ponta, com uma senha mestra que só você conhece.
  • O aplicativo acessa apenas os arquivos que ele mesmo cria no seu Google Drive (pasta “uNotes Sync”).
  • Não existe servidor nosso: os dados vão direto do dispositivo para o seu Google Drive.
