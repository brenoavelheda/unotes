Política de privacidade do uNotes

Última atualização: 2 de novembro de 2026.

Esta política descreve como o uNotes, aplicativo de anotações pessoais para Windows e Android, trata os seus dados.

Dados que o desenvolvedor coleta

Nenhum. O uNotes não coleta dados pessoais, não usa ferramentas de análise ou rastreamento, não exibe anúncios e não opera servidores próprios.

Dados de usuário do Google acessados

O uNotes acessa apenas os arquivos que ele próprio cria no Google Drive do usuário, por meio do escopo https://www.googleapis.com/auth/drive.file (drive.file). O aplicativo não acessa outros arquivos do Drive.

Como esses dados são usados

Exclusivamente para armazenar e sincronizar as notas e os anexos criptografados do próprio usuário entre os seus próprios dispositivos.

Compartilhamento

Os dados nunca são compartilhados, vendidos ou transferidos a terceiros.

Armazenamento e segurança

O conteúdo é criptografado de ponta a ponta no dispositivo antes de ser enviado. As credenciais e os tokens de acesso permanecem nos dispositivos do usuário.

Exclusão dos seus dados

Para remover os dados do uNotes:

  • revogue o acesso do aplicativo em https://myaccount.google.com/permissions;
  • exclua a pasta “uNotes Sync” no Google Drive;
  • desinstale o aplicativo.

Uso Limitado

O uso e a transferência, pelo uNotes, de informações recebidas das APIs do Google seguem a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado.

Contato

Dúvidas sobre esta política podem ser enviadas pela página de issues do repositório.
